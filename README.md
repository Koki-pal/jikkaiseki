# 実解析学 学習ノート（外部公開版）

このフォルダの中身をそのまま静的サイトとして公開すると，Claude のアカウントがなくても誰でも開けます．

## 公開のしかた（どれか 1 つ）

### GitHub Pages（おすすめ）
1. GitHub でアカウントを作り，新しいリポジトリ（例：jikkaiseki）を Public で作る．
2. 「Add file」→「Upload files」で，このフォルダの中身（index.html，app.js，content フォルダ，ai フォルダなど）をすべてアップロードする．
3. リポジトリの「Settings」→「Pages」で，Source を「Deploy from a branch」，Branch を main，フォルダを / (root) にして保存する．
4. 数分後に https://ユーザー名.github.io/jikkaiseki/ で開けるようになる．

### Netlify / Cloudflare Pages
アカウントを作り，このフォルダをドラッグ＆ドロップでアップロードする．

## 注意
- index.html をパソコンで直接ダブルクリックして開くと，一部の機能が動きません．上のようなサイトに置いて https で開いてください．
- 学習記録・メモ・AI との会話は，各自のブラウザに暗号化して保存されます．別の端末で続けるときは，右上の名前ボタン →「記録をファイルに書き出す」で保存し，別の端末のログイン画面で「記録ファイルを読み込む」を使います．
- 「AI で開く」（Claude / ChatGPT）ボタンは，ai フォルダにあるノートの全文テキストの URL と指示文を渡して新しい会話を開きます．同時に全文をコピーするので，URL を読めなかったときは貼り付けるか，「ファイルに保存（.md）」したものを添付してください．
- 内容を変更したときは，ai フォルダの全文テキストも作り直す必要があります．
